# feichti01.github.io

Root page of the GitHub Pages user site: https://feichti01.github.io/

Static HTML in the FEICHTIQ corporate design, mirrored from the
www.feichtiq.com landing page (`scripts/build_site.py` in `feichti01/feichtiq`):
brand colour tokens, self-hosted Sora (OFL), deep-sea hero images and logo
lockups come from that repository. Rebuild assets there, then copy them here.

- `index.html` — apps (Homing, GasBlender), support links, about
- `privacy/` — privacy notice for this site (GitHub Pages hosting)
- `css/site.css`, `fonts/`, `img/` — shared style and assets
- No scripts, no cookies, no third-party requests.

Project sites keep their own paths and are not affected by this repository:
`/support/`, `/gasblender/`, `/homing-releases/`. Do not add top-level
folders with those names here, they would shadow the project sites.

Published from `main`, root folder. Impressum: https://www.feichtiq.com/impressum/
